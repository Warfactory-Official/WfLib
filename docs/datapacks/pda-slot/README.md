Copy this folder into a 1.21.1 world's datapacks/ and reload/rejoin with Curios 9.5.1 installed on both sides. This grants players one dedicated pda slot and accepts wflib:pda there. It is an example only, not auto-enabled or bundled as active mod data.

WARNING: the charm.json example uses replace:true with an empty list to remove the default PDA charm assignment. It also replaces other packs' charm assignments. Remove that file to allow both slot types; for a real modpack, preserve your other charm item entries in its values list. Curios slot configuration/data is the user's choice.
