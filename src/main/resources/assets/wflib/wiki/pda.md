# PDA

Handheld tablet. Hold it in the **main hand**.

## Controls

| action | result |
|---|---|
| use | raise the screen, mouse drives the cursor |
| use / Esc | lower it again |
| sneak + use | item action (monitor: copy channels) |
| mouse wheel | scroll |

## Apps

- Telemetry: event log of linked drones and missiles
- Cameras: channels linked to this PDA
- Drones: status, tasking, dispatch
- Radar, Map, Satellites, Radio, Alerts
- Terminal: typed commands
- Wiki: these articles

Every item with a tutorial shows a hint in its tooltip. Press the tutorial key (default **F1**) while pointing at it in an inventory, or while holding it, and the PDA is pulled out on that article.
